# Saboteur 92 — миссия лаборатории

Вторая ночь в горе Saboteur II. Вчера Нина перенастроила ракету и ушла. Сегодня под недостроенным центром всё ещё работает **секретная лаборатория**. Задача: найти её, **запустить штатный аварийный сброс** и выйти до обвала.

> Find the lab. Start the dump. Leave before it falls.

## Три калитки

Каждая калитка — два легитимных пути. Бой — запасной, не цель.

| Калитка | Через охрану | Через головоломку |
|---|---|---|
| 1 — внутреннее кольцо | Коридор у спавна, ключ с поста | Шкаф-люк (crouch), обход восточного патруля |
| 2 — дверь в пещеры | Охраняемый лифт в лабу | Служебный лифт: прочитать номера **02, 06, 11** на ящиках `?` |
| 3 — пульт сброса | Документ + жетон, два контура в зале | Перемычка интерлока → один пульт |

## Предметы

- **Key** — пропуск во внутреннее кольцо.
- **Orders** (document) — регламент сброса; без него пульт не примет команду (если перемычка не снята).
- **Card** (bomb slot) — жетон оператора сброса.
- **Dump timer** — фитиль после запуска сброса; выход — западный туннель внизу карты.

## Тревога

Первый длительный контакт со стражем включает тревогу. Это не game over: фитиль укорачивается (50→35 с), у выхода появляется дополнительный патруль.
