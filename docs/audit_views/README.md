# Снимки раскладки тайлов

`python tools/saboteur_rip/slice_world_tiles.py`

- `slice_overlay.png` — клетка 8×8 как один пиксель: небо / грунт / структура / синий кирпич / мозаика / остаток
- `slice_leftover.png` — полный размер, только неразложенные клетки (лестницы, мебель, окна)
- `slice_rebuild.png` — собранная карта в пикселях источника (8192×4608), без мебели
- `slice_rebuild_quarter.png` — та же карта в 1/4 для быстрого просмотра
- `slice_report.json` — счётчики

## Baseline текущего разложения (до переработки)

Замерено на `saboteur2_world2.png` (8192×4608, сетка 1024×576, 589 824 ячейки):

| Метрика | Значение |
|---|---|
| Совпадение пересборки с источником по ячейкам | 90.1% (531 443 из 589 824) |
| Совпадение по не-небу | 86.5% (359 443 из 415 494) |
| Уникальных ячеек в источнике | 2991 |
| Уникальных тайлов в атласах | 75 (earth 44, wallpaper 28, structure 2, mosaic 1) |
| `solid_cells` | 212 833 |
| Выброшено в остаток (`slice_leftover.png`) | 29 361 ячейка |
| `ladder_rle` | пустой |

Полностью чёрные ячейки (`black_n == 64`) — 163 278 (27.7% карты): это и порода
снаружи, и воздух внутри комнат, поэтому физика по цвету не различает их.
Все чёрные ячейки образуют 243 связные компоненты; 49 крупных (≥40 ячеек)
содержат 161 726 ячеек (99%).

## Гейты проходимости и визуального регресса (после переработки на чанки)

Карта теперь хранится нативно: 64 сцены-чанка в `scenes/world/chunks/` со слоями
`TileMapLayer` + `CollisionLayer` (физика из `s2_collision_tileset.tres`).

- `test/integration/test_level_playable.gd` — чанки инстанцируются с тайлами,
  `World/Ladders` и `World/Lifts` построены, спавн не внутри solid.
  Запуск: `godot --headless --path . -s addons/gut/gut_cmdln.gd -gdir=res://test/integration/ -gexit`
- `tools/capture_map_view.gd` — рендерит 4 точки (spawn/rooftop/interior/cave)
  для визуального регресса. Требует дисплей (на Windows — оконный режим, не
  `--headless`): `godot --path . -s tools/capture_map_view.gd -- <out_dir>`
- `tools/saboteur_rip/labyrinth.py` — проходимость. Две метрики:
    - `geometry_reached` — body-aware flood fill (тело Нины 2×3, без гравитации).
      Мозаика не solid, поэтому цифра высокая и не равна «комнатам».
    - `reached` — BFS платформера (гравитация/прыжки/лестницы/лифты): **23007**
      клеток, **95.0%** standable. Ключ / документ / бомба / диверсия достижимы.

Текущий baseline коллизии (`s2_collision_grid.json`):
`solid=215106`, `ladder=8848`, `oneway=1146`.
Чёрное и чёрное с редкой синей крапинкой — solid. Обои (густой синий кирпич) и
мозаика — бумага. Швы `structure` tile 4 — не solid. Белые лестницы сквозь монолит
— climb. Красный кирпич секретки — облицовка. Горизонтальная/наклонная железная
решётка — oneway; вертикальная стойка не пол.
Лифты растянуты по шахтам фан-карты (люки 1–2 клетки пропускаются).

Документ больше не в запечатанной шахте: проход открылся вместе со швами между комнатами.
