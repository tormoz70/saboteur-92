# Расследование проходимости карты (playability)

Статус: **модель коллизии зафиксирована, проходимость миссии открыта**. Дата: 2026-09-17.

## Исходная проблема

Проверка проходимости (`tools/saboteur_rip/labyrinth.py`, BFS от спавна) застревала на
**155 клетках** — Нина не могла выйти из верхней части стартового здания.

## Правила коллизий (фан-карта, согласовано)

| Визуал | Слой | Solid? | Комментарий |
|---|---|---|---|
| Просто чёрное | любой | ✅ да | грунт/порода |
| Чёрное с редкой синей крапинкой | любой | ✅ да | тот же грунт (не обои) |
| Синий кирпич обоев | `wallpaper` | ❌ нет | густой синий штрих, бумага |
| Зелёная мозаика | `mosaic` | ❌ нет | задняя стена комнаты |
| Мебель, монитор на стене, окна | `interior` / `fg` | ❌ нет | декор; Нина идёт «перед» спрайтом |
| Ящики, fg | `fg` | ❌ нет | |
| Спрайты гардов | fan screenshot | — | артефакты; стираются в `fan_map_cleanup.py` |
| Тонкий чёрный шов 1 клетка | `structure` tile 4 | ❌ нет | стык Spectrum-экранов |
| Белая штриховка сквозь монолит | `interior` 4/5 и пары | climb | лестница на синей бумаге ZX |
| Красный кирпич секретки | `structure` tile 3 | ❌ нет | облицовка; люк над лестницей — climb |
| Белая металлическая балка, горизонтальная | `interior` решётка | ✅ да | пол: по ней ходят герои и охрана |
| Белая металлическая балка, вертикальная или под углом | `interior` решётка, 45° | ❌ нет | задний план, герои проходят мимо |
| Трос между зданиями | pure sky line у края крыши | rope | бег по тросу; остановка → падение вниз |

Генератор: `tools/saboteur_rip/build_collision.py`.
Сетка: `solid≈209k`, `ladder≈8840`, `oneway≈1146`, `rope≈15k`, `empty≈356k`.

## Что блокировало «проходы»

Циановые двери почти не solid (405 дверей, 28 solid-клеток). Барьер — **вертикальные швы**
`structure` tile 4 (`...##.#.`), по одной клетке на всю высоту этажа. BFS не мог ни пройти,
ни перепрыгнуть: проверка полёта шла на высоте стояния.

Те же швы резали документ в «запечатанной шахте». После снятия tile 4 документ достижим.

## Лифты

Декодер ставил `top==bottom` (кабина не едет). Реальные шахты — колодец с люками в 1–2
клетки на каждом этаже (LEVEL U/T/S/…). `build_collision.py` растягивает шахту по пустому
колодцу, пропускает тонкие люки, останавливается о небо.

HQ-лифт: **408–4016** px. Все 6 лифтов достижимы из BFS.

## Физика прыжка в BFS

Из `player.gd`: обычный прыжок ≈ **5.5 клеток** вверх / **9** вбок.

В `labyrinth.py` теперь `JUMP_CELLS=6`, `JUMP_HORIZ=10` (было 3/8). Дуга считается по
вершине прыжка, поэтому ящик/парапет можно перелететь; полноразмерная стена по-прежнему
держит.

## Текущие цифры

| Метрика | Было (155) | После мозаики | Сейчас |
|---|---|---|---|
| BFS `reached` | 155 | ~6788 | **30702** |
| standable достигнуто | — | ~69% | **98.7%** (14576 / 14770) |
| Ключ / документ / бомба / диверсия | нет | частично | **да** |
| Выход / `m02` | нет | да | `m02` да; выход — маркер в породе |
| Лифты | мёртвые | мёртвые | **6/6** |

Люк — крапинка на колонне лестницы (крыша склада, INVINCIBILITY): вся пачка
спекла становится climb, чистый чёрный грунт нет. Маркер `m02` достижим.

Правило пользователя: белые металлические балки твёрдые, только когда лежат
горизонтально, — по ним ходят. Вертикальные и наклонные балки — задний план,
герои проходят сквозь них. Сверка по чанкам (27.09.2026): все 847 клеток
горизонтальных балок `solid`, вертикальные стойки и раскосы 45° пустые.
CI проверяет правило по тайлам чанков: `tools/explore/check_beams.py`.
Вертикальные трубы тоже не пол. Пещера справа от HQ (Т-туннель)
достижима с порога HQ.

Спавн и ключ висят в воздухе над крышей; BFS сажает ноги через `_drop`.
