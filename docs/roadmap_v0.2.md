# Roadmap v0.2 — играбельная сборка на телефоне

Цель: превратить техническое демо в игру, которую не стыдно дать поиграть на
Android. Движение, мир на TileMap-чанках и миссия лаборатории уже работают;
не хватает звука, оболочки, живых врагов и проверки на реальном устройстве.

Генератор мира на LLM ([ai_world_generator_plan.md](ai_world_generator_plan.md))
на паузе. Из него берём только проверки достижимости — они полезны и для
ручной карты (этап 1).

Этапы упорядочены по зависимостям. Каждый этап — отдельный PR.

## Этап 2 — канат в правое здание (2–3 дня)

В оригинале радиовышка на крыше правого здания (с ракетой) достижима по
канату из центрального комплекса. Канат нарисован и на фанкарте, и в
чанках, но не работает: вышка считается недостижимой.

Где канат (проверено по `saboteur2_world.png` и `chunks_json`):

- красная пунктирная линия, **y = 672 png px (строка ячеек 84)**,
  x ≈ 4088–6103: от перекладины правого края центрального комплекса до
  перекладины радиовышки;
- в чанках — слой `interior1`, локальная строка 12 чанков `chunk_04_01`
  (x 0–127) и `chunk_05_01` (x 0–122).

Почему не работает:

- на слое коллизии под канатом **нет ни одной ячейки `rope`**;
- x 4096–4471 — обрывки `solid` (28 из 47 ячеек, с дырами);
- x ≈ 4472–5943 — пусто, Нина проваливается;
- x 5944–6103 — коллизия перекладины вышки (`solid` / `oneway`);
- в игроке нет механики каната, тайл `rope` без физики;
- единственные ячейки `rope` на карте стоят не там — на бочках и бутылках
  крыши (y 384–392, x 2968–3176).

Задачи:

- [ ] Способ передвижения (решено с пользователем): **бег по канату
  поверху, стоять на нём нельзя** — остановка или разворот посреди каната
  означают падение вниз. Так же задумано в докстринге `build_collision.py`,
  и пользователь помнит, что в оригинале Нина падала. Сверить с
  дизассемблером оригинала (`assets/reference/original/s2/.../S2CORE.MAC`)
  и оставить параметры (допустимая пауза, скорость) настраиваемыми.
- [ ] Коллизия: вся строка 84 от x 4088 до 6103 — ячейки `rope` (атлас
  x = 4), обрывки `solid` на канате убрать, стыки с обеими перекладинами
  проверить. Ложные `rope` на бочках крыши стереть.
- [ ] Механика в игроке — отдельный `RopeController` по образцу
  `LadderController`: вход на канат с перекладины на бегу, держит только
  при горизонтальной скорости, сход на перекладину на другом конце,
  срыв и падение при остановке.
- [ ] Ребро `rope` в `tools/explore/build_nav.py` и в `chunk_validator.gd`,
  чтобы проверки достижимости видели переход между зданиями.
- [ ] Пересчитать достижимость: радиовышка должна стать достижимой;
  обновить [maze_exploration.md](maze_exploration.md).
- [ ] GUT: проход до конца на бегу, падение при остановке посреди каната.

**Критерий:** Нина проходит по канату от центрального комплекса до
радиовышки и обратно; проверка достижимости видит вышку.

## После v0.2 — решение по арту

Для публикации нужна собственная графика мира. План: перерисовать ~300
уникальных тайлов 8×8, которые покрывают 99% карты, и подменить атласы.
Геометрия и коллизия не меняются: `tile_id_map.json` append-only, коллизия
живёт на отдельном слое. Здесь ИИ полезнее, чем в генерации уровней.

Генерацию чанков LLM возвращать под конкретную цель — вторая миссия или
бонусная карта, — а не для перегенерации существующего мира.

## Правила работы

- Коммит и пуш — только по просьбе пользователя; файлы стейджить явно.
- Не коммитить `.mcp/`, `.godot/`, строку `McpBridge` в `project.godot`.
- Перед PR: gdlint, GUT, `--demo`, `--demo-fuse`, `--demo-tilt`.
